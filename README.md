# نظام إدارة مدرسة بلقاس

مرحبًا بك في نظام إدارة مدرسة بلقاس المبني على Laravel. يوفر النظام أدوات شاملة لإدارة العمليات الأكاديمية والإدارية، بما في ذلك إدارة المستخدمين، الفصول، المواد، الحضور، الدرجات، الشؤون المالية، والمكتبة.

## دليل المستخدم
تم إعداد دليل عربي مبسّط موجّه لطاقم المدرسة غير التقني يوضح كيفية تسجيل الدخول، إدارة الطلاب والمعلمين، متابعة الحضور، إصدار التقارير، والتعامل مع الشؤون المالية.

- [docs/دليل-النظام.md](docs/دليل-النظام.md)

## البدء السريع للمطورين
1. تثبيت الاعتمادات الخلفية:
   ```bash
   composer install
   ```
2. تثبيت الاعتمادات الأمامية:
   ```bash
   npm install
   ```
3. إنشاء ملف البيئة وتوليد مفتاح التطبيق:
   ```bash
   cp .env.example .env
   php artisan key:generate
   ```
4. ضبط إعدادات قاعدة البيانات ثم تنفيذ الترحيلات مع البيانات الأولية:
   ```bash
   php artisan migrate --seed
   ```
5. تشغيل الخادم المحلي:
   ```bash
   php artisan serve
   ```

## حسابات الاختبار
تمت إزالة الحسابات التجريبية من واجهة تسجيل الدخول. للاطلاع على بيانات الدخول الافتراضية، راجع الملف النصي الموجود في جذر المشروع:

- [demo-accounts.txt](demo-accounts.txt)

> **هام:** استخدم هذه الحسابات في بيئات التطوير فقط، واحرص على تغيير كلمات المرور الافتراضية عند التشغيل في بيئة إنتاجية.

## المساهمة والدعم
- لمراجعة البنية أو المساهمة في التطوير، يرجى اتباع أفضل ممارسات Laravel القياسية وتنفيذ الاختبارات قبل رفع أي تغييرات.
- في حال وجود أي استفسار أو ملاحظات، الرجاء فتح تذكرة دعم عبر قناة التواصل المعتمدة لدى المدرسة.
